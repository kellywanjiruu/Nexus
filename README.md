## ✨ Features

- **Hero Section** - Bold headline with animated stats and CTA buttons
- **Features Grid** - 6 interactive feature cards with hover effects
- **Pricing Section** - 3 pricing plans with monthly/yearly toggle
- **Testimonials** - Customer reviews with company logos
- **Contact Form** - Working form with validation
- **Newsletter Signup** - Email subscription in footer
- **Smooth Animations** - Scroll-triggered fade-ins and hover effects
- **Fully Responsive** - Mobile-first design, works on all devices

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, Grid, Custom Properties)
- Vanilla JavaScript (ES6+)
- Font Awesome 6
- Google Fonts (Plus Jakarta Sans)
